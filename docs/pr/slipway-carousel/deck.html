Slipway · postmortem06 / 08

The app's own SLO saw zero errors. Clients saw 48%.

11:57↑ node stopped 12:0512:16
  • The gateway's only controller was on the lost node (default 5-minute eviction)
  • Kyverno's fail-closed webhook was there too, and blocked the evictions
  • Fixed the same day: retries + outlier detection, 2 replicas, 30 s tolerations, webhooks on CREATE/UPDATE only
